Features

Everything in your living room, in one tab.

Add your TVs once. Switch between them with a click or the keys 1–9.

Live screen

Real H.264 video from Android TV and Fire TV, decoded in your browser. Not screenshots.

▦

Wall of TVs

Every TV at once: a fresh screenshot, the app in front and the volume. Power each one from its tile.

⌘

A proper remote

D-pad, transport, volume, live typing, app launcher and HDMI inputs. Keyboard shortcuts included.

⌂

Home Assistant, natively

An add-on with no login screen, a real media_player per TV, MQTT discovery and a dashboard card.

Supported TVs

Quick start

Up and running in a minute.

Pick how you run things at home.

Intel/AMD and Apple Silicon / Raspberry Pi, one line:

$ docker run -d --name tvhub --restart unless-stopped \
    -p 127.0.0.1:8080:8080 -v tvhub-data:/data \
    ghcr.io/xavilitoh/tvhub:latest
# then open
$ open http://localhost:8080

For Home Assistant OS / Supervised. Opens from the sidebar, and Home Assistant signs you in.

  1. Add the repository to Home Assistant (button below).
  2. Install TVHub, start it and turn on Show in sidebar.
  3. Optional: turn on install_integration and the integration sets itself up.

The integration gives every TV a media_player and the dashboard card.

  1. HACS → ⋮ → Custom repositories → https://github.com/xavilitoh/tvhub, category Integration.
  2. Download TVHub and restart Home Assistant.
  3. Add integration → TVHub (or accept TVHub discovered when you use the add-on).

Build it yourself with Docker Compose:

$ git clone https://github.com/xavilitoh/tvhub && cd tvhub
$ docker compose up -d --build
$ open http://localhost:8080
